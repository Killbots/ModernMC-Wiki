# Welcome to BetterTowny

Welcome to **BetterTowny**, a survival world built around towns, player-run communities, progression, and a player-driven economy.

Whether you're here to build a home, grow a business, join a town, take on quests, or develop your skills, this wiki explains how the server works.

## A good first session

1. Read the server rules and learn the basic commands.
2. Explore the world and decide whether you want to settle independently or join a town.
3. Try a job that matches how you like to play.
4. Build up a financial cushion before committing to expensive land or upgrades.
5. Ask in chat or Discord if a feature behaves differently from this guide.
