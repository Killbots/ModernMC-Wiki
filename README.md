# BetterTowny Wiki Starter

An editable, Markdown-first wiki starter for a modern Towny survival server. The pages are written to be safe to customize: replace bracketed placeholders and remove any feature that your server does not use.

## Pages included
- Home
- Ranks
- Economy
- Towny
- mcMMO
- Jobs
- Quest-writing guidelines and an editable quest template

## Suggested use
These pages can be published in GitHub, GitBook, MkDocs, Hugo, or another Markdown-based documentation site. They are plain Markdown and do not require a special editor.

## Before publishing
1. Replace every `[EDIT: ...]` placeholder with your server's actual settings.
2. Confirm all commands and permissions against the installed plugin versions.
3. Add links to your Discord, store, rules, support channel, and server address.
4. Make sure perks are consistent across ranks and obtainable through your intended paths.
5. Have staff review the public-facing rules and economy descriptions.

## Important
This is a starter wiki, not a claim that every listed command or feature is enabled on your server. Plugin configurations differ. Verify commands, prices, limits, and cooldowns in-game before publishing.
